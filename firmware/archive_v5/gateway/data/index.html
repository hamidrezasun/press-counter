Output relays K2-K5 (COM / NO / NC, 2.5 A)

Manual outputs can be switched here, from MQTT (out_on / out_off) or the USB console; the mode of each output is set under Settings. Switching ON needs "Allow remote start", switching off is always possible. At most 4 outputs are on at once.
