# Archive: press counter v5 (two boards, STM32F103 + ESP8266)

Kept for reference only - superseded by the single-board ESP32 design v6 (see ../README.md).

* `fabrication/` - the last complete, DRC-clean v5.2 exports (MAIN 188 x 104 mm with five relays, PANEL 150 x 96 mm).
* `main/`, `panel/` - KiCad projects as they were when v6 was started (MAIN contains the unfinished v5.3 USB-programming changes).
* `tools/` - the v5 generator scripts (design.py, layout_main.py, layout_panel.py ...); they expect to live in `hardware/tools/`.
* `BOM_press_counter_v5.xlsx` - BOM of v5.3 (about 5.1 M Toman).
